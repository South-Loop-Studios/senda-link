# Security

Senda Link runs inside `coreaudiod`, so a memory-safety bug in it is a bug in a system daemon.

Please report vulnerabilities privately: open the repository's **Security** tab and choose
**Report a vulnerability**. Do not open a public issue. Include the Senda Link and macOS versions
and what you observed; a crash log helps, a working exploit is not needed.

We aim to acknowledge within five working days and to fix confirmed problems in a signed release,
coordinated with you before disclosure. Only the latest release is supported.
